## Conjutos de datos utilizados para el entrenamiento de los modelos expertos

Para el entrenamiento de los modelos expertos, utilizamos diversos conjuntos de datos públicos que contienen información relevante sobre diferentes enfermedades crónicas no transmisibles. A continuación, se presentan los conjuntos de datos utilizados:

### Diabetes
* https://archive.ics.uci.edu/dataset/891/cdc+diabetes+health+indicators
### Heart Disease
* https://archive.ics.uci.edu/dataset/45/heart+disease
* https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset
    * mencionado en: https://doi.org/10.1016/j.sasc.2026.200490
* https://data.mendeley.com/datasets/dzz48mvjht/1
* https://archive.ics.uci.edu/dataset/519/heart+failure+clinical+records
* https://www.kaggle.com/datasets/kamilpytlak/personal-key-indicators-of-heart-disease
### Pulmonary Disease
* https://www.kaggle.com/datasets/prakharrathi25/copd-student-dataset
    * mencionado en: https://doi.org/10.1038/s41598-025-02952-6
* https://archive.ics.uci.edu/dataset/880/support2
* https://www.kaggle.com/datasets/kamilpytlak/personal-key-indicators-of-heart-disease
* https://www.kaggle.com/datasets/meirnizri/covid19-dataset/data
### Liver Disease
* https://www.kaggle.com/datasets/fedesoriano/cirrhosis-prediction-dataset
* https://archive.ics.uci.edu/dataset/423/hcc+survival
* https://archive.ics.uci.edu/dataset/878/cirrhosis+patient+survival+prediction+dataset-1
* https://www.kaggle.com/datasets/sunilsah905/non-alcoholic-fatty-liver-disease/data
* https://archive.ics.uci.edu/dataset/60/liver+disorders
### Chronic Kidney Disease
* https://archive.ics.uci.edu/dataset/336/chronic+kidney+disease
